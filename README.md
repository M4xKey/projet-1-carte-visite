# Carte de visite

Un template de carte de visite en ligne, réalisé en HTML/CSS/JS pur (sans framework), dans le cadre d'un apprentissage du développement web.

## Fonctionnalités

- Page présentant un nom, un titre, une courte présentation, une liste de compétences et des moyens de contact
- Design en carte centrée, responsive (mobile/desktop)
- Bouton pour copier l'email en un clic
- Toggle mode clair / mode sombre, avec mémorisation du choix (`localStorage`)

## Utilisation

1. Cloner ou télécharger le projet
2. Ouvrir `index.html` dans un navigateur
3. Remplacer les placeholders (`Prénom NOM`, `ton.email@example.com`, les compétences, etc.) par tes propres informations

## Structure

```
├── index.html   → contenu et structure de la page
├── style.css    → mise en forme, thème clair/sombre
└── script.js    → bouton copier email + toggle mode sombre
```
